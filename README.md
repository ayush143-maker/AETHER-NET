# 🌐 Global Web Traffic Matrix

A cyberpunk-styled network intelligence dashboard that visualizes global packet routing, DNS resolution, and ISP telemetry in real-time.

![Vercel](https://img.shields.io/badge/Deployed%20on-Vercel-black)
![React](https://img.shields.io/badge/React-18.3-61dafb)
![Vite](https://img.shields.io/badge/Vite-5.3-646cff)
![Tailwind](https://img.shields.io/badge/Tailwind-3.4-38bdf8)

## 🚀 Features

- **Live GeoIP Resolution** — Real-time domain/IP metadata via `ip-api.com`
- **Traceroute Pipeline** — 5-7 hop simulation through major IXPs worldwide
- **Animated World Map** — SVG vector routing trails with pulsing nodes
- **Cyberpunk Terminal** — Auto-scrolling telemetry logger with timestamps
- **Threat Analytics Grid** — Simulated packet loss, jitter, and port analysis
- **Mobile-Responsive** — Optimized layouts for all screen sizes
- **Zero Auth Required** — All APIs are free and public

## 🛠️ Tech Stack

- **React 18.3** — Component architecture
- **Vite 5.3** — Build tooling + dev server
- **Tailwind CSS 3.4** — Utility-first styling
- **Vercel** — Global Edge deployment

## 📦 Installation

```bash
git clone <your-repo-url>
cd internet-traffic-visualizer
npm install
npm run dev
```

Visit `http://localhost:3000` to view the dashboard.

## 🚢 Deploy to Vercel

1. Push code to GitHub
2. Import repository on [vercel.com](https://vercel.com)
3. Framework preset auto-detects as **Vite**
4. Click **Deploy**

Build Command: `npm run build`
Output Directory: `dist`
